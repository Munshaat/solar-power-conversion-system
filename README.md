# Solar-Powered DC–DC and DC–AC Conversion System

**Type:** Academic power electronics simulation project  
**Tools:** Proteus circuit simulation (as illustrated in the report)  
**Area:** Power Electronics, DC–DC Conversion, Inverters

## Project Description
This project focuses on simulating a solar-powered electrical conversion system using a 24 V DC input. It explores converting DC power into AC power using an H-bridge inverter and converting DC voltage to different levels using boost and step-down converter circuits. The report includes circuit diagrams, simulation waveforms, and explanations of the power conversion stages.

## Reported tasks
- Generate an approximately 50 Hz AC sine-wave output from a 24 V DC input using an H-bridge and output filtering.
- Boost 24 V DC to 110 V DC using a MOSFET switching circuit with a 555 timer signal generator.
- Produce a 240 V peak-to-peak square-wave output, using an inverter and transformer stage.
- Convert 110 V DC to 5 V DC using a step-down converter configuration.

## Evidence
The report includes simulated schematics, oscilloscope captures, a system block diagram, and an explanation of the conversion stages. The reported values are simulation results rather than independently validated hardware measurements.
